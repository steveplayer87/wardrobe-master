# 元件庫吸收與重構對照日誌 (Component Integration Log)

日期：2026-11-08
版本基底：Wardrobe Master v119

## 1. 緣由與背景
使用者提供了一份針對衣櫥專案進行架構重構的早期分支檔案 (`元件庫修改計劃.zip`)。經詳細比對，該分支屬於早期實驗版本（代碼行數約 2,192 行，而目前穩定生產版本已擴展至約 9,901 行）。
若直接以該重構包覆蓋，將會導致多項近幾週關鍵功能嚴重遺失（包括 Cloudflare KV 雲端備份、Notion 生活標籤雙向同步、洗衣籃多選與指定日期洗衣、日曆衣服下緣對齊等）。

## 2. 吸收與保留之核心重點

### A. 吸收的基礎核心架構：
1. **純函式查詢規範 (`queryItems`)**：
   - 保留將單品搜尋、過濾、排序抽離為純函式之邏輯，避免散落在各個 View 之中。
2. **視窗返回堆疊機制 (`pushModal`)**：
   - 記錄視窗歷史堆疊，解決過去使用單一 `modalReturnTo` 變數在多層彈窗（例如確認彈窗中再開日期選擇器）時可能被提前清除或誤退回首頁的問題。
3. **無全域污染原則**：
   - 各瀏覽實例內部維護自身狀態，避免全域變數相互覆蓋。

### B. 保留並受到嚴格保護的生產環境新邏輯：
1. **Cloudflare Worker 雲端同步與防呆機制** (`syncEverythingToCloud`, `checkCloudSyncSafety`, `restoreWardrobeFromCloud`)。
2. **Notion 生活標籤與洗衣日記雙向同步** (`syncLifeConsumablesWithCloud`, `syncLaundryDiaryTag`)。
3. **最新洗衣籃全套功能**：
   - 待洗耗材與單品並列呈現。
   - 洗衣籃多選選取模式 (`isLaundrySelectMode`)。
   - 吸底置頂操作列 (`sticky bottom actions`)。
   - 指定清洗日期（含今天/昨天/前天/大前天/自訂日期）。
   - 單品縮圖確認與安全回寫。
4. **作息換日 offset 機制**（凌晨 02:00 生活日換日）。
5. **月曆穿搭服裝水平對齊與下緣基準貼合演算法**。
6. **睡衣（連續 14 天週期）服役中管理與暫存衣架置頂**。
